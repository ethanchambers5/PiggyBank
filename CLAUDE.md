# Piggy Bank

A spending tracker. You log purchases, they get sorted into categories automatically, and you can see
what you spend the most on. You set a weekly budget per category and the app warns you when a week is
going over budget. The goal is a mobile app; for now it's a phone-sized web prototype running on fake data.

## Current state (prototype v1)

- `app/piggybank.html` is the source: one self-contained file (vanilla HTML/CSS/JS, no build step).
  It is also published as a claude.ai Artifact: https://claude.ai/artifact/AhmwSD3XPfoGfC5b4B7SPQ
- `app/index.html` is generated from it with a doctype/head wrapper so it opens directly in a browser.
  After editing `piggybank.html`, regenerate it:
  `python3 -c "s=open('app/piggybank.html').read();open('app/index.html','w').write('<!doctype html>\n<html lang=\"en\">\n<head>\n<meta charset=\"utf-8\">\n<meta name=\"viewport\" content=\"width=device-width, initial-scale=1, viewport-fit=cover\">\n</head>\n<body>\n'+s+'\n</body>\n</html>\n')"`

### Features
- **Home**: spent this week vs. total budget, a pace marker, over-budget/at-risk alerts, spending by category, latest purchases.
- **Spending**: purchases for the selected week grouped by day; tap one to edit, recategorize or delete.
- **+ button**: add a purchase; category is auto-guessed from the merchant name (`RULES` keyword list).
- **Budgets**: editable weekly budget per category with progress bars; reset demo data.
- **Trends**: last 6 weeks (ending at the latest week with purchases) stacked bar chart vs. budget line, average week per category.
- **Import a bank statement**: CSV only, read in the browser (never uploaded). Auto-detects separator, header row,
  date/description/amount columns, date order (MM/DD vs DD/MM) and whether purchases are negative or positive; the user
  can override each in the sheet. Skips income, transfers/card payments and duplicates, cleans bank descriptions
  (`cleanMerchant`) and auto-categorizes. First import can replace the demo data (`data.demo = false`).
  Includes a built-in sample statement (`sampleCSV`). PDF statements are not supported yet.
- Week switcher goes back 8 weeks, or further if imported purchases are older. Weeks start Monday. Currency is USD.
- Always light theme with a white background (no dark mode, by request).

### Data
- Demo data is generated by `makeDemo()` from a fixed seed, relative to today's date
  (random everyday purchases + monthly bills like phone, internet, gym, Netflix).
- Changes are saved in the browser's localStorage (`piggybank.v1`) only.
- Categories: Groceries, Eating out, Coffee, Transport, Shopping, Entertainment, Bills, Other.
